# Dados

Os arquivos de dados não são versionados neste repositório. Para reproduzir os resultados, coloque nesta pasta:

- `train.csv`: 4000 linhas com `pair_id`, os 10 atributos e `stars`
- `test.csv`: 2000 linhas com `pair_id` e os 10 atributos
- `sample_submission.csv`: formato da submissão (`pair_id,stars`)
